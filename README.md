# Marchen 个人博客

一个使用 Astro、Tailwind CSS、MDX、Pagefind 和 Giscus 预留能力搭建的个人博客与知识花园。

## 开发

```bash
bun install
bun dev
```

## 构建

```bash
bun run build
bun run preview
```

所有源码、Markdown 和配置文件均使用 UTF-8 编码。

## 内容编写

博客 / 碎念 / 项目的路径、frontmatter 与本地图片目录约定见 `AGENTS.md`。

```bash
bun run check:content
```
